## 目标

实现显式条目归档与取消归档。归档作为独立于业务状态的生命周期标记，保留稳定 ID，并将记录放入项目 root/archive。

## 验收

已确认接口（当前尚未实现）：`itemark archive <ID>...` 与 `itemark unarchive <ID>...` 支持按 ID 批量操作。归档不改变业务状态；默认 list、search、summary 隐藏归档记录，三者支持 `--include-archived`；list 的 `--archived` 只列归档记录。`--all` 仍只控制已废弃记录，与归档筛选独立。show、check 和 ID 引用在 items 与 archive 中均有效。

## 当前下一步

实现归档/取消归档及查询选项；检查默认隐藏、显式包含/仅归档、show/check/引用仍可访问，并确认业务状态和 ID 保持不变。
