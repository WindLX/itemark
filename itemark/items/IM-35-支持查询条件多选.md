## 目标

支持在查询记录时为一个条件选择多个值，特别是同时筛选 `todo` 与 `in_progress` 状态。当前 `list` 的 `--status`、`--kind`、`--group` 各接受一个值，`search` 只接受搜索文本，没有条件组合选项。

## 验收

仅 list 的 --group、--kind、--status 支持重复参数，同一字段任一值匹配即通过，不同字段条件同时满足。相同值可去重；逗号仍为单个字面值，不支持逗号拆分。现有单值写法、数值 ID 顺序、--all、raw 状态值、JSON/文本输出保持兼容。search、summary 和单条记录的 ID 定位/编辑参数不扩展。空结果清楚列出多值筛选条件及 OR 语义。

## 当前下一步

无；筛选行为由 CLI 集成测试持续覆盖。

## 历史进展

- 2026-09-29：用户提出希望一次选择多个查询条件值，例如同时筛选 `todo` 和 `in_progress`。查阅当前 CLI 帮助：`list` 的 `--status`、`--kind`、`--group` 均为单值选项，`search` 仅接收文本；查询内容“多选”未命中已有事项。
- 2026-09-29：推荐讨论方向为同一字段多个值按 OR、跨字段按 AND，并优先考虑 status/kind/group。重复 flags 只是候选形式；命令覆盖面和具体语法仍未确认，当前不实现。

## 证据

- `itemark list --help`：当前 `--group`、`--kind`、`--status` 各为单值选项。
- `itemark search --help`：当前仅接收一个搜索文本参数，无其他筛选选项。
- `itemark search '多选' --json`：当前记录中匹配数为 0。
