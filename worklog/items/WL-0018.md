## 目标

人读文本用 Rust 的排版与着色库渲染，让长输出（list / summary / check / show）一眼能看出层级与状态；同时提供开关，保证管道、日志与 CI 里拿到的仍是纯文本。

## 验收

- 终端下的人读输出带颜色与强调（标题、字段名、状态、检查发现）。
- `--color never`、`NO_COLOR` 环境变量与非 TTY 三种情况下输出纯文本，不含任何 ANSI 转义。
- JSON 输出永不着色。
- `--color` 是全局参数，对所有子命令生效。
- 测试覆盖：强制 `never` 时 stdout 不含 `\x1b[`；强制 `always` 时含。

## 当前下一步

选定着色库并接入 output 层，再把各命令的人读渲染改成走同一套样式。

## 历史进展

- 2026-09-29：用户要求人读输出彩色化、用 Rust 库增强渲染，并且颜色要有可选开关以保证兼容性。
