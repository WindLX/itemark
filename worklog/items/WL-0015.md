## 目标

让「字段类型」这套词表只有一处定义，并让 `kind check` 复用 `check` 的发现表示，避免同一条规则写三遍。

## 验收

- 新增或修改一种字段类型时只改一处；声明校验、取值校验、`kind check` 三者共用同一份类型判定。
- `kind check` 的文本与 JSON 由同一份发现结构（`Issue` / `IssueKind` / `CheckReport`）渲染，不再先造 `serde_json::Value` 再反解 `target` / `detail`。
- `kind check` 的现有行为（退出码、人读文本）不变。

## 当前下一步

先把类型词表收敛为一次解析加一次取值校验，再把 `src/cli/kind_cmd.rs` 的 JSON 构造改用 `CheckReport`。
