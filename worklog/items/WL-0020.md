## 目标

让 CLI 的人读提示与帮助文案在简体中文项目里自洽：不残留英文内置说明，不出现半角冒号与错位的必填标记，空结果有明确提示。

## 验收

- [x] clap 内置的 help/version 选项说明与 `help` 子命令说明改由项目语言呈现，`--help` 与各子命令帮助不再出现 "Print help"/"Print version"。
- [x] 全局参数在子命令帮助里归入「全局选项」，值名统一为可读形式（`<kind 名称>`、`<group 名称>`、`<auto|always|never>`）。
- [x] `kind show` 的字段行使用语言相关的冒号与顺序：`- status：enum [todo|in_progress|blocked|done]（必填）`。
- [x] `list`/`search` 无匹配时输出「无匹配记录」（英文为 no matching records），不再只打印一个标题。
- [x] 完成规则报错里的多个分节名用语言分隔符连接。

## 当前下一步

无；如需继续，从 code review 结论派生新记录。

## 证据

- 实现：`src/cli/args.rs`（`localized_command`/`localize`、`help_heading`、`value_name`）、`src/main.rs`（改用本地化命令树）、`src/output.rs`（field_line 与 no_matches 标签）、`src/cli/kind_cmd.rs`、`src/cli/item.rs`。
- 实测：`./target/debug/worklog --help`、`add --help`、`group --help`、`show --help` 均无 "Print help"，且含「全局选项」「打印帮助」「打印版本」；`kind show work` 输出 `- status：enum [todo|in_progress|blocked|done]（必填）`；本仓库 `list --status blocked` 输出「无匹配记录」。
