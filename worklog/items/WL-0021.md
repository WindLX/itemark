## 目标

补齐 CLI 文案的语言边界：帮助里的段落标题与默认值标记本地化，诊断文本恢复英文，`docs/cli.md` 的帮助边界说明如实，并收紧相关断言。

## 验收

- [x] `--help` 及各级子命令的帮助不残留 clap 硬编码脚手架（`Usage:`/`Options:`/`Arguments:`/`Commands:`/`Print help`/`Print version`/`[default: …]`）。
- [x] 帮助段落标题为「用法/命令/选项/参数/全局选项」，全局选项与局部选项仍分组呈现。
- [x] 完成规则的诊断句恢复英文连接词，项目语言不再渗入英文诊断。
- [x] `docs/cli.md` 如实描述帮助语言边界，并写明用法错误等诊断文本固定为英文。
- [x] 「帮助不随 `--language` 切换」有测试；空结果提示覆盖 `search`；管道关闭断言收紧为 stderr 为空且由 SIGPIPE 终止。

## 当前下一步

无。

## 进展

- 2026-09-29：评审指出 `docs/cli.md` 宣称「帮助在编译期固定为简体中文」与实际不符：clap 仍打印英文的 `Usage:`/`Options:`/`Arguments:`/`Commands:` 与 `[default: auto]`。本次逐一消除。
- 段落标题改由参数自己的 `help_heading` 决定：`-h/--help`、`-V/--version` 归入「全局选项」，位置参数归「参数」，其余选项归「选项」；子命令段落用 `Command::subcommand_help_heading("命令")`。
- 硬编码的 `Usage:` 用自定义 `help_template` 换成「用法：」，其余占位符与 clap 默认模板一致。
- 去掉 `--color` 与 `log --section` 的 `default_value`，默认值改由帮助文本和代码兜底，避免 `[default: …]` 英文标记。
- 开启 clap `unicode` feature，CJK 取值名按两列计宽，帮助列不再错位。
- 内置 help/version 说明同时改写 `long_help`，避免将来某个参数带长帮助时英文说明回潮。
- 诊断句里的语言相关分隔符回退为英文 ` and `；空结果提示与 `search` 共用同一处文案。
