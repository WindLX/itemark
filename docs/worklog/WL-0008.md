# Build overview and handoff views

## 目标

Generate a current overview and handoff from the records and queries, with clear source IDs and an as-of time. A generated view is not another writable state source.

## 验收

- [ ] Build a live overview from current records, groups, kinds, lifecycle, and business-state fields; do not require a persistent index.
- [ ] Include the source record IDs and generation time in overview and handoff output.
- [ ] Include unfinished, blocked, completed-but-unverified, and next-step information where the records provide it.
- [ ] Human-readable text is the default; support JSON output using the same query/result behavior.
- [ ] Render human-readable summary and handoff text in the configured project language; this project's default is `zh-CN`. Keep machine identifiers and JSON keys stable.
- [ ] Generation is read-only by default. Saving a snapshot requires an explicit option and includes its generation time and sources.
- [ ] Regenerating after source changes reflects current source values; report behavior not actually exercised as unverified.

## 当前下一步

After WL-0007 establishes whole-record checks, build read-only text/JSON overview and handoff views.
