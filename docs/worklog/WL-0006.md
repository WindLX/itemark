# Update, move, and log record changes

## 目标

Support focused updates to record metadata or selected Markdown sections, moving records between groups, and appending progress without rewriting untouched user content.

## 验收

- [ ] Update one selected field or configured section while preserving all untouched Markdown text.
- [ ] Move a record to another group without changing its project-wide ID or breaking ID-based references.
- [ ] Append a dated progress entry without deleting or rewriting prior history.
- [ ] Detect a changed source file before replacing it and report a conflict rather than silently overwriting it.
- [ ] Keep kind definitions and templates read-only to CLI commands; expose show/check only.
- [ ] Report behavior not actually exercised as unverified.
